# Thriftly 🚀
Automated Rotational Savings & Escrow Fintech Platform

### What it does:
Thriftly digitizes traditional rotational savings (Ajo/Esusu) for market traders. It features real-time cloud data synchronization, automated escrow buffers, and multi-lingual localization (English, Hausa, Pidgin, and Yoruba).

### Tech Stack:
- Frontend: React, Vite, Tailwind CSS, Lucide Icons
- Backend & Cloud Database: Firebase Firestore (Real-time `onSnapshot` sync)
- Deployment: Vercel (Live Production)
